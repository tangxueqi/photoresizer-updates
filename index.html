v1.29 更新内容：去掉叶片上的误识别

  1. 切掉误检"尾巴"——文字块会和叶片阴影连成一个巨大的连通块。实测这个块从 y=462 一直拖到 y=780，其中 y>642 的部分每行只有不到 40 个像素（文字行是 150~350），而且完全不含水印色。原来它是整块被收进来的，叶片上就多出一片红膜
  2. 按行密度断裂判定——从行密度峰值向两侧走，连续多行低于峰值 35% 就判定文字带结束，带外像素全部裁掉。文字行密度沿纵向变化平缓，误检尾巴是骤降，两者很容易分开
  3. 精确率 77.6% → 85.3%，四个字覆盖率仍有 95.7% / 96.5% / 98.1% / 97.9%，几乎没有为了精确牺牲完整
  4. 没有过度收紧——试过把色度阈值从 0.022 提到 0.030，精确率只涨 1.4 个点，但"影"字覆盖率会掉到 85.7%，笔画开始缺失，所以最终保持 0.022。剩下的"误差"里 85% 其实带明显水印色，是水印的羽化边，去掉反而会留淡色残影

v1.28 更新内容：自动识别终于把四个字认全了

  1. 修掉"只认出中间几笔"——上一版按"绝对颜色"找水印，而水印是同一种半透明色压在深浅不同的底上：压在深灰扇叶上偏青蓝，压在浅灰铝座上几乎是淡蓝白。用固定颜色范围去找，只能咬住其中一部分，实测只覆盖了水印笔画的 56%
  2. 改为按"色度偏移"识别——不再看颜色绝对值，而是看每个像素"相对同亮度区域的色偏方向"。半透明水印不管压在哪，色偏方向是一致的，于是深色扇叶、浅色铝座上的笔画能一次认全。实测四个字覆盖率 96.6% / 96.7% / 98.1% / 98.8%
  3. 文字带按纵向重叠率收块——一个字常横跨条带边界，按"块中心是否落在带内"会把"冰"的上下沿整块丢掉；改成按重叠比例收，边角笔画不再缺
  4. 误检清理——闭运算后丢掉细碎孤立块，扇叶反光、画面边缘这类误判不再画上红膜；无文字水印的图仍会正确提示"未识别到"

v1.27 更新内容：去水印重做，自动识别不再手涂

  1. 打开带字水印的图，自动识别、不用涂抹——进入去水印页后自动分析整张图，把「整幅图里共用同一颜色、横向铺开、笔画式稀疏」的那一片文字判为水印，识别到就直接用红膜标出，你确认后点「开始去除」即可。原理是按颜色分簇统计，不依赖 OCR，所以中英文、艺术字、半透明字都能抓
  2. 主体不再被连带抹掉——新的掩膜算法只保留与水印笔画连通的部分，并且对封闭笔画内部的小孔做有上限的填充：字被笔画围住的干净扇叶、纹理不会被整块糊掉
  3. 手涂仍然保留，可以和自动识别叠加——自动没抓全的地方（比如字压在金属高光上）用手指补两笔，二者取并集后一起处理；右上角还有「自动识别」按钮可以重新跑一次
  4. 认不出会明确告诉你——如果图里没有符合特征的文字（比如纯风景、纯商品图），会提示「未识别到文字水印，请用手指涂抹水印区域」，不会乱涂乱删

v1.24 更新内容：彻底修复抖音解析超时

  1. 找到并解决解析超时的根因——抖音分享页现在已经变成「引导打开抖音 App」的中转页，页面自身从不播放视频、也不会请求视频地址，所以原来靠后台网页去「截取视频请求」的做法必然等不到，表现为 15 秒超时

安装步骤

  1. 点击上方按钮下载 .apk 文件
  2. 下载完成后，在浏览器通知栏或「文件管理 → 下载」中找到它
  3. 点击安装，系统会提示「允许安装未知来源应用」，选择允许
  4. 安装完成，桌面出现「冰影电商素材」图标

使用提示

  1. 首次进入需授权相册读取权限，用于选择图片
  2. 尺寸默认 800 × 800，可手动改宽高
  3. 格式默认 JPG；切到 PNG 后压缩质量滑块会置灰（PNG 为无损格式）
  4. 处理完成后点「保存到相册」，图片会存到 Pictures/PhotoResizer/
  5. 去水印——首页选「去水印」→ 选 1 张图 → 自动识别文字水印（红膜标出，可手指补涂）→「开始去除」→「保存到相册」；笔刷可换粗细，涂错可撤销，右上「自动识别」可重跑
  6. 分享接收——在豆包等 App 里选中图片 → 分享 → 选择「冰影电商素材」，图片直接进入本 App 已选列表
注意：微信或 QQ 传输 APK 时可能自动加后缀（如 .apk.1）导致无法安装。 若下载后装不上，请用手机自带浏览器打开本页面直接下载，或改名为 .apk 后再安装。
